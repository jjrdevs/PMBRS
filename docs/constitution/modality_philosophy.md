## Modality Definition

A modality is a structured time-indexed information source that can be deterministically aligned to the canonical temporal system.

Examples:

- wearable telemetry,
- browser telemetry,
- application telemetry,
- journals,
- calendar events,
- interventions,
- music/media context.

## Modality Categories

PMBRS distinguishes modalities by epistemological role.

### Observational Modalities

Directly measured signals.

Examples:

- heart rate,
- motion,
- foreground application usage.

### Declarative Modalities

Explicit user-provided information.

Examples:

- interventions,
- annotations,
- schedules.

### Subjective Modalities

Self-authored semantic representations.

Examples:

- journals,
- reflections.

### Inferred Modalities

Probabilistic derived interpretations.

Examples:

- inferred walks,
- inferred context labels,
- inferred behavioral states.

## Modality Constraints

All modalities must:

- preserve lineage,
- preserve uncertainty,
- support deterministic alignment,
- expose modality metadata,
- conform to shared structural contracts.

## Semantic Separation

Core behavioral representations prioritize observational modalities.

Subjective and inferred modalities remain partially separated to:

- reduce semantic leakage,
- preserve interpretability,
- prevent self-report contamination of behavioral structure.
