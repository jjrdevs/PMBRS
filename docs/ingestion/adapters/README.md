## Rule for development

- Read the roadmap first for strategy and decision-making.
- Use the active plan for the current coding task.
- Treat the roadmap as the long-term authority and the milestone docs as the near-term execution plan.

## Current active milestone

The current active milestone is app usage telemetry.

This milestone is focused on:

- app usage as the first rich signal,
- local-only storage,
- opt-in collection,
- daily summary generation,
- short raw-retention windows,
- fail-closed permission handling.
