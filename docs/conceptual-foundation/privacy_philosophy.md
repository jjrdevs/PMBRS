## Privacy Philosophy

PMBRS is local-first and privacy-preserving by default.

Behavioral data should remain under direct user ownership and control whenever feasible.

## Storage Philosophy

PMBRS prioritizes:

- local storage,
- append-only architecture,
- derived representations over exhaustive surveillance,
- minimal irreversible data loss.

Cloud synchronization is not part of the constitutional architecture.

## Sensitive Data Principles

PMBRS should avoid collecting or storing:

- screenshots,
- raw audio,
- keystroke streams,
- message bodies,
- exhaustive browsing contents,
- invasive surveillance artifacts.

Sensitive modalities should prefer:

- aggregation,
- embeddings,
- semantic summaries,
- metadata-level representations.

## Access Philosophy

Frontend systems,
visualization systems,
and downstream applications should operate with minimal required access to sensitive artifacts.

Core storage remains separate from downstream interfaces.

## Privacy Boundaries

External providers,
LLM systems,
and APIs should remain replaceable and isolated from authoritative storage whenever feasible.
