# pmbrs — Personal Model of Behavioral Regulation System

Behavioral analytics framework that captures, analyzes, and visualizes multi-modal behavioral data for deep work optimization.

## Layout

```
docs/                   # All PMBRS documentation (constitution, ADRs, design docs)
src/                    # Core application source code
schemas/                # Schema definitions
tests/                  # Test suite
scripts/                # Build/test helper scripts
config/                 # Configuration files
.mobile/               # Mobile event dashboard component (mobile-event-dashboard ties into this)

Questions              # Project Q&A / knowledge document (large living doc: ~46KB)
```

## Conventions

- mobile-event-dashboard is a **component of PMBRS**, not independent — events tracking feeds the behavioral model.
- The constitutional principles and architecture docs live in `docs/`. New design decisions go as ADRs in `docs/adr/`.
- Project documentation (including `PROJECT_SUMMARY.md`) belongs in `docs/`, never at workspace root.
- Mobile-specific files stay under the `mobile/` subdirectory or reference the mobile-event-dashboard project which is maintained alongside this one.
